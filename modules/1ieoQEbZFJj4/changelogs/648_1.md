## What's new?

### Features
- Responsive layouts with a new navigation rail
- Configurable WebUI launch modes
- Per-file HTTP response headers for webroot, with a new headers editor screen
- Ability to mutate the `ksu` interface ([guide](https://mmrl.dev/guide/webuix/interface-mutation))
- New `ksu.pm()` interface; the old package APIs are deprecated

### Improvements
- KernelSU IO migrated to JavaScript classes, and the KSU package manager is now exposed as a JS class
- Added a version property and function to `KsuIO`
- Shortcuts now open the WebUI in a new-process activity
- WebUI state is destroyed on dispose (mmrlx bumped)
- `SuFile` init now launches explicitly on the IO dispatcher
- `ButtonGroup` replaced with `HorizontalButtonGroup`

### Fixes
- Fixed append in `OutputStream`
- Fixed value handling in the config editor input dialog

### Translations
Updated Arabic, Chinese (Simplified), French, German, Italian, Spanish and Ukrainian.

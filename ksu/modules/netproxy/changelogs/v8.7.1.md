## 版本 8.7.1（2026-11-19）

### Android 管理器

- 管理器统一采用 MIUIX OS4 Glass，更新导航栏、菜单、弹层和应用图标。不支持实时折射的设备会在同一个安装包内回退。外观跟随系统明暗，仍可调整配色与界面缩放。

- 代理页的策略组标签可左右滚动，滑动仅浏览，点击才切换。新增、编辑、删除入口集中到右上角的「管理策略组」菜单；编辑时可调整兼容的组类型。

- 修复前后台切换时仪表盘服务卡片反复收起、代理节点选中标记闪烁的问题。回到前台重新确认核心状态前，不会发送可能作用于旧核心的节点切换。

- 应用代理改用右上角搜索入口。JSON 快捷工具栏可横向滚动，悬浮在代码上方并随键盘避让；日志页将常用操作收纳到菜单，清空前需确认。

### 路由与规则集

- 新建路由规则时可选择「指定策略组」，按域名、IP 或应用包名等条件选择出口。仍被路由引用的策略组不能直接删除；复杂规则继续用原生 JSON 编辑。

- 更新内置广告拦截规则、中国 IP 规则集和非中国地域规则集。

### 升级说明

- 从 8.7.0 升级可选「保留现有数据」。从 8.6.2 或更早版本直升，请先备份并遵循 [8.7.0 的升级说明](https://github.com/Fanju6/NetProxy-Magisk/releases/tag/v8.7.0)。

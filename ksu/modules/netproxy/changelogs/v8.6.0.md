## 版本 8.6.0（2026-10-15）

### 管理器连接

- Android 管理器全面改用模块 HTTPS 管理接口，不再申请 Root 权限或通过 Root Shell 执行命令；模块仍需 Root 环境。

- 管理器自动获取可信连接资料，无需手动复制密钥；使用独立的安装证书和随机凭据保护本机管理接口。

- 服务状态、流量、节点与订阅通过共享事件连接更新，切换页面时复用连接。

### 模块管理接口

- 新增独立于 sing-box 的 HTTPS API，支持节点、订阅、配置、日志与服务管理；核心停止时仍可访问。

- HTTP API 与 CLI 共用业务校验和配置事务；已接受的写入不因客户端断开而中断，保存失败与运行时同步失败分别反馈。

- 接口监听失败后自动退避恢复，无需重启代理核心。

### 应用与节点

- 应用标签、图标与多用户信息由模块统一提供，图标按需读取并复用缓存，刷新时保留已显示的图标。

- 没有节点的分组不再显示 Auto-Fastest 卡片。

## 版本 8.7.4（2026-11-27）

### 路由规则

- 路由规则按「应用」「域名、IP 与端口」「高级规则」分组显示，每条规则直接展示匹配对象和流量去向。分组只影响列表展示，不改变内核的匹配顺序。

- 新增或编辑规则改用底部 Glass 弹窗。可搜索并多选已安装应用，也可手动填写包名；删除入口移到编辑弹窗右上角，需二次确认。复杂原生规则仍可用 JSON 编辑。

### 日志与稳定性

- 服务启动失败时，日志会尽可能指出内核配置错误、进程退出或最后一次就绪检查的具体原因，不再一律显示「等待服务就绪失败」。

- 统一服务日志与内核日志的卡片样式；清空日志后仍可滚动收起标题栏。

- 修复三键导航模式下，资源页面的底部弹窗可能被系统导航栏遮挡的问题。

- 更新内置广告拦截、AI、中国 IP 和非中国地域规则集，以及 AndroidX 依赖。

### 升级说明

- 从 8.7.x 升级可选「保留现有数据」。建议一并更新模块内附的管理器，已有节点、策略组和路由无需重新配置。

- 从 8.6.2 或更早版本直升，请先备份并遵循 [8.7.0 的升级说明](https://github.com/Fanju6/NetProxy-Magisk/releases/tag/v8.7.0)。

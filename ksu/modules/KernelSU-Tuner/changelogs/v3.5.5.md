Install through the KernelSU manager under Modules - Install from storage, then reboot.

Three switches were writing to the system even when turned off.

The thermal unlock switch, while off, forced every `thermal_zone` to `enabled`. That means each apply re-armed all the throttling limits even though you never asked for the unlock. It leaves them alone now.

Same pattern for the IPv6 switch: while off, it set `disable_ipv6=0` on every interface. On a network where IPv6 does not actually work, the system tries it first and waits for the timeout before falling back, which makes things slower. It does nothing now, and the uninstall script behaves the same way.

The DNS preset pointed the system private DNS at `dns.google` on the performance profile. That does not resolve in China. It uses `opportunistic` now: encrypted when the network offers it, otherwise the carrier DNS, and it cannot break connectivity. Balanced and powersave stop touching that setting entirely; before they would turn off a private DNS you configured yourself.

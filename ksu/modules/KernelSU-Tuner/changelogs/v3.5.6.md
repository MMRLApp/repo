Install through the KernelSU manager under Modules - Install from storage, then reboot.

Two things were making the S25 Ultra slow.

First, the balanced profile replaced the CPU governor. Samsung ships `performance` as the governor, and the balanced candidate list started with `schedutil`, so applying the balanced profile quietly downgraded the whole device. Balanced no longer touches the governor at all. Powersave still switches it, and performance/gaming still set `performance`.

Second, the IO tuning walked every entry under `/sys/block`. On this device that is 160 `loop` devices plus a couple of dozen `dm-*` mappings, so every apply wrote close to four hundred nodes. It now skips `loop`, `dm`, `ram`, `zram` and `sr`, and only touches real storage.

Verified against a mock of the S25 Ultra layout: after applying balanced, both clusters keep `performance` and their original frequency range.

If you already have it installed, either uninstall and reinstall cleanly, or run `tuner.sh revert` first so the old governor value goes back.

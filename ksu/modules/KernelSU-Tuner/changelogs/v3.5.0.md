Install through the KernelSU manager under Modules - Install from storage, then reboot.

**The WebUI is bilingual now.** There is a switch button in the top right corner of both interfaces, next to the title. It swaps between Chinese and English and remembers your choice.

The English interface is `webroot/index.en.html`. It came from PR #4 by FlukyLizard and is used exactly as submitted, no edits. The Chinese one stays at `webroot/index.html`, which is still what the manager opens by default.

Both are fully self-contained. Switching reloads the page, so nothing is left half-translated.

**Not covered yet:** the shell scripts in `bin/` still write Chinese into logs and command output, so those lines show Chinese in the English interface too. Same for the one-line description in `module.prop` that the manager displays. PR #4 already pointed this out.

Drop the zip into the KernelSU manager under Modules - Install from storage, then reboot.

New in this build:

**CPU frequency limits** - profiles now set scaling_max_freq and scaling_min_freq, not just the governor. The range is picked from the frequencies your kernel actually exposes, so nothing is hardcoded. Toggle with the CPU 频率上下限 switch.

**Boot-failure rollback** - the module counts boots. If the system does not come up three times in a row, it rolls back every kernel and custom parameter it changed, writes the disable flag and turns itself off. This is what protects you when a custom parameter turns out to be wrong.

**Wipe protection** - a new guard with three modes:

- 增强模式: kills the process the moment a wipe command is seen

- 普通模式: pauses and asks you first, through the WebUI

- 不防护: logs only

It watches running processes and boot scripts for rm -rf on system paths, mkfs, dd to block devices, fastboot wipe/erase/format and shred. Temporary paths such as /tmp, /cache and /data/local/tmp are deliberately left alone.

Also: updateJson is now set, so the manager can tell you about new versions.

Everything from before is unchanged: four profiles, adaptive switching, charge limiting, app standby management, per-app policies, custom parameters, display tuning, initrc services and the WebUI.

The white flash on opening the WebUI. It was two things stacked.

The `html` element had no background colour, only `body` did. Until `body` renders, the WebView paints the root element, which defaults to white. That is the flash you see. `html` now uses the same dark colour as `body`, and `color-scheme: dark` is set so form controls and scrollbars follow.

`theme-color` is set too, which the WebView uses for its own loading surface.

The language redirect was worse. It lived in the script at the end of `body`, so if you had picked English before, opening the WebUI would fully load the Chinese page first, then jump to the English one. Two loads, two flashes. It is in `head` now and uses `location.replace`, so only one page loads and no extra history entry is created.

Also the first `load()` call now runs in `setTimeout(..., 0)`, so the browser paints the interface before doing any of the shell round-trips.

Expect it to still take a moment to open. That is the manager creating the WebView and injecting the bridge, which the module cannot shorten. What is gone is the white part.

Install through the KernelSU manager under Modules - Install from storage, then reboot.

Four of the daemons could not actually be turned off. `autopilot`, `guard`, `appwatch` and `wipeshield` all started unconditionally when asked, and the watchdog asks every five minutes. So turning one off in the WebUI lasted until the next watchdog pass. Each one now checks its own switch first and refuses to start when it is disabled.

The watchdog also looked for `wipeshield.pid` while the script writes `shield.pid`, so it never saw the wipe guard as running. That is mapped now.

The language button stored your choice but nothing ever read it back. Both interfaces now check it on load, so picking English actually sticks.

The released zip was missing `module.yaml`, the icons, both READMEs, the license and the changelog. That was true of every release since 3.1.0. It now contains the full tree, which also means the GPL text ships with the binary.

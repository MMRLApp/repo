Install through the KernelSU manager under Modules - Install from storage, then reboot.

This fixes the slowdown reported on the Galaxy S25 Ultra, and it was my bug.

The frequency floor and ceiling were taken from the first and last entry of the kernel's frequency table. That assumes the table is sorted ascending. On kernels that list frequencies from high to low, max and min came out reversed, and every core ended up pinned to the lowest step. Reading the list is now order-independent: the real minimum and maximum are compared directly.

Running the same code against a descending table now gives min 800 MHz / max 1.8 GHz instead of 300 MHz for both.

Also in this build:

- `walt` and `sugov_ext` added to the governor candidates. Qualcomm and Samsung kernels expose those, so the CPU governor switch was silently doing nothing there.

- `watermark_scale_factor` lowered from 150 to 100. 150 makes the kernel start reclaiming with plenty of memory still free.

- boot TRIM is off by default now. On large flash fstrim saturates IO for a minute or two after boot.

- balanced no longer caps the GPU performance level at half.

- removed three functions that were defined twice in `tuner.sh`, plus a duplicated frequency block.

If you are on 3.5.3 or older and your device feels slow, uninstall and reboot, then install this. Do not overwrite while the old config is still applying.

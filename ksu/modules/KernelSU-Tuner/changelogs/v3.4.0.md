Install through the KernelSU manager under Modules - Install from storage, then reboot.

**Kernel extensions.** A new `kernel.sh` covers the areas this module had not touched: devfreq bus and memory-controller clocks, KSM deduplication, transparent hugepages, `schedtune` boost, the full three-value TCP buffers, touch boost, and the filesystem ceilings (inotify, file-max, nr_open). Each section has its own switch and all of them are off by default.

**Config versioning.** Config writes now go through a temp file and an atomic rename rather than `sed -i`, so an interrupted write can no longer leave a half-written file. There is a `SCHEMA` field and a migration path that fills in new keys on existing installs without disturbing what is already set.

**SELinux.** The module now ships `sepolicy.rule` with 184 rules covering the nodes it writes. Previously some writes could be silently blocked on enforcing devices.

**Watchdog.** `watchdog.sh` checks autopilot, guard, appwatch and wipeshield every five minutes and restarts anything that died. They used to fail silently.

**Also**

- periodic TRIM, interval in days

- switch to powersave automatically below a battery level you choose

- dry run now reports what the kernel extensions would change

- WebUI: kernel extension switches, watchdog controls, devfreq listing

**Fixed**

- safe mode appended `SAFEGUARD=0` to the config, creating a duplicate key. It rewrites in place now

- the boot-failure counter was left as an empty file when cleared

Everything from earlier versions is unchanged.

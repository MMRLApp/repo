Install through the KernelSU manager under Modules - Install from storage, then reboot.

Config writes are atomic now. Four scripts still used `sed -i` followed by an append, which leaves a half-written `config.conf` if the write is interrupted. They all go through a temp file and a rename now.

User input reaching the shell is escaped. The custom parameter, backup import, preset name and per-app fields used to be wrapped in bare single quotes, so a value containing a quote broke the command. Input is escaped properly now.

`tuner.sh` and `cfg.sh` shared the same lock directory, so running both could stall one for up to 150 seconds. `cfg.sh` uses its own lock now.

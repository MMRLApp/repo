Install through the KernelSU manager under Modules - Install from storage, then reboot.

This build is mostly about the things that were missing rather than new switches on top of old ones.

**Config export and import** - everything you have configured (options, per-app rules, custom parameters, whitelist) goes into one JSON file on your storage. Import merges rather than replaces, so keys the backup does not contain are left alone. Useful when moving to a new device or sharing a setup.

**CPU frequency limits** - the profiles used to change the governor and nothing else. They now set scaling_max_freq and scaling_min_freq too, snapped to frequencies your kernel actually advertises. Ranges are 10-45 percent for powersave up to 60-100 for gaming.

**Range checking for custom parameters** - if a node has min and max files next to it, a value outside that range is refused before it is ever written. There is a force option if you know what you are doing.

**LMK and memory pressure** - min_free_kbytes scaled by installed RAM, lowmemorykiller minfree per profile, watermark tuning. This is usually the real reason background apps get killed, and it was not covered before.

**ZRAM sizing** - if zram0 has no size yet it gets 75 percent of RAM, with mkswap and swapon. Existing sizes are left alone.

**Thermal zone selection** - unlocking thermal no longer disables every zone blindly. You choose which ones, cpu and gpu by default. A new zones command lists every zone with its type, mode and temperature.

**Autopilot** - follows the system battery saver and can force a profile during a time window, including windows that cross midnight.

Everything from earlier versions is still there: four profiles, adaptive switching, charge limiting, app standby management, per-app policies, display tuning, boot-failure rollback, wipe protection and the WebUI, now with 8 tabs.

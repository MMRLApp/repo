Install through the KernelSU manager under Modules - Install from storage, then reboot.

**License** - the repo now carries the GPL-3.0 text that module.yaml was already claiming.

**Custom presets** - save your own named profile on top of one of the four built-ins. Names are validated, and you cannot shadow a built-in.

**Per-app parameters** - a node and value can be bound to a package and written only while that package is in the foreground. Range checking applies. Useful for capping one game's clocks without slowing everything else.

**Dry-run preview** - before applying anything, ask what would change. It prints every node with its current and target value and writes nothing at all.

**Also in this build**

- a tools tab in the WebUI for backup, presets, per-app parameters and the preview, 9 tabs total

Everything from earlier versions is unchanged: four profiles, adaptive switching, charge limiting, app standby management, custom parameters, display tuning, boot-failure rollback, wipe protection and config export/import.

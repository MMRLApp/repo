Drop the zip into the KernelSU manager under Modules - Install from storage, then reboot.

**If you had v3.0.2 installed, uninstall it first.** The module id changed from `ksu_tuner` to

`KernelSU-Tuner` to match the registered id, so the manager treats them as two different modules.

What changed in this build:

- `module.prop` and `module.yaml` now use `id=KernelSU-Tuner`, matching the registered id

- module paths follow the id, so the module now lives at `/data/adb/modules/KernelSU-Tuner`

- the initrc file and its service names were renamed to match

- the runtime data directory intentionally stays at `/data/adb/ksu_tuner` so existing configuration survives

Everything else is unchanged from v3.0.2:

- Four profiles (powersave / balanced / performance / gaming) driving CPU governor, GPU levels, IO scheduler and readahead, VM tunables, network stack, DNS and ZRAM compression

- Adaptive switching based on temperature, screen state and charging, with hysteresis

- Charge limiting with automatic resume

- App Standby Bucket management with a per-app whitelist

- Per-app profiles driven by whichever app is in the foreground

- Custom sysfs and proc parameter editor, every change backed up first

- Refresh rate and touch sampling tuning

- initrc services

- WebUI console, no external dependencies

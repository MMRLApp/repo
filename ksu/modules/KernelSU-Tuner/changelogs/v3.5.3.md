Security work this release.

Custom parameters could write to a handful of nodes that either kill the device or run arbitrary code: `/proc/sysrq-trigger`, `/proc/sys/kernel/core_pattern`, `/proc/sys/kernel/modprobe`, `/proc/sys/kernel/hotplug`, `/sys/kernel/uevent_helper`, and the raw memory devices. Those are refused now.

The wipe guard missed several ways to erase a device: `blkdiscard`, `sgdisk --zap`, `mke2fs`, `fdisk`, `parted`, and `dd` aimed at `/dev/mmcblk` or `/dev/nvme`. A path containing `..` could also slip past the allowlist. All covered now.

Backup import copied config values straight in, newlines included, so a crafted file could append extra keys to `config.conf`. Newlines are flattened to spaces now.

`appwatch.sh set` did not validate its arguments, so a package name containing `|` corrupted the rules file. It checks both the package name and the preset name now.

Two places in the WebUI read a value back out of a DOM attribute and pasted it into a shell command without quoting. Both are escaped now.

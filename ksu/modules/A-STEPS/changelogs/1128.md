拟步［HyperOS］

在小米 / 红米 / POCO（HyperOS）上，基于系统计步库模拟步数，让第三方应用读取到自然、可追溯的步数数据。

总步数 = 真实步数 + 模块写入，每一条写入都记进账本，随时可查、可撤销。

模块信息

名称：拟步［HyperOS］

标识：A-STEPS

作者：酷安 @浠浠浠

适用：小米 / 红米 / POCO，HyperOS

环境：Magisk / KernelSU（WebUI 管理）

数据目录：/data/adb/拟步/

主要功能

- 开机服务守护，无需核心破解、无需 App 后台，低 CPU 占用；多种写入通道自动探测

- 三种配速：手动（随机 / 固定步数）、自动、倍数跟随；活动曲线支持均匀 / 上班 / 夜跑

- 每日目标与随机目标、达标自动停止、24 点后自动重新运行、指定星期独立计划

- 秒级「写入间隔」与「每条间隔」、合并写入、息屏停写 / 亮屏一次性补写、低电量暂停

- 一键增加步数、撤销补写；开始 / 停止 / 增加等危险操作均为弹窗二次确认

- 完整账本与运行日志、查看全部、七日步数曲线、今日轨迹、距离与热量估算

- 自检诊断、一键导出报告到 Download/拟步

- 更新检测 4 条线路自动优选，「更新与交流」卡片直达发布页与群组

界面

6 套风格自由切换：清新 / 经典 / 尺规 / 云母 / 便当格 / 新粗野，支持明暗模式；

另有「星轨」独立界面（深空轨道可视化），配置与数据完全同步。

42 项参数集中在 WebUI 配置页，保存即生效，无关设置按条件自动隐藏。

安装

在 Magisk / KernelSU 中刷入，完成后重启一次；更新后建议重启，

或在「配置 → 运行控制」点「重启全部进程」以系统级方式重建后台进程。

升级保留运行日志与账本，配置需重新设置。

注意

仅支持小米全系设备；请勿冻结电量与性能，保持设备时间与网络时间同步。

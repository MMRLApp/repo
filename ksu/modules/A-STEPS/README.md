## 📖 项目简介

**拟步［HyperOS］**（模块 ID：`A-STEPS`）是面向小米 / 红米 / POCO（HyperOS）的 KernelSU / Magisk 模块。它在系统计步库上模拟步数，让第三方应用读取到自然、可追溯的步数数据：**总步数 = 真实步数 + 模块写入**，每一条写入都记进账本，随时可查、可撤销。

模块提供手机端 WebUI，可管理计步任务、调整 42 项参数、查看账本与运行日志。退出 WebUI 后计步照常运行。项目持续迭代中，实际功能以安装包中的 WebUI 与模块行为为准。

## 📦 下载与安装

- 打开 **[GitHub Releases 下载页](https://github.com/xiaoji0308/Steps/releases)**。

- 下载对应版本的模块 ZIP 安装包。

- 打开设备上的 KernelSU 或 Magisk 管理器，选择从本地安装 ZIP。

- 按安装器提示完成操作，**安装或更新后请重启手机一次**。

- 安装完成后打开模块 WebUI，确认运行状态正常，再按需调整配置。

**仅支持小米全系设备**（小米 / 红米 / POCO，HyperOS）。请勿冻结电量与性能，保持设备时间与网络时间同步。

升级会保留运行日志与账本，**配置不迁移，需通过 WebUI 重新设置**。请勿将源码压缩包误当作模块安装包；应下载 Release 附件中的可安装 ZIP。

## 🕹️ WebUI 使用说明

- **首页：** 查看今日步数与完成度、步数构成（真实 / 写入）、活跃时段、运行情况与七日步数曲线。

- **记录：** 按日期查看补写账本明细与运行日志，支持查看全部、复制记录、自检诊断与导出报告（`Download/拟步`）。

- **配置：** 运行控制、目标策略、时间与独立计划、智能配速、收尾与作息、省电与写入、账本与估算、界面风格共 9 组设置，保存即生效，无关设置按条件自动隐藏。

- **界面风格：** 6 套风格与明暗模式随时切换；「星轨」为独立界面，右上角可返回经典界面，数据与配置完全同步。

页面选项可能随版本调整，请以当前安装版本显示的内容为准。

## ❓ 常见问题

### 更新检查失败

- 检查设备网络是否能够访问 GitHub。

- 确认仓库已经发布 Release，而不只是提交了代码或上传了普通文件。

- 确认 Release 附件中有可安装的模块 ZIP。

- 如果暂时无法检查更新，可先从 [Releases 页面](https://github.com/xiaoji0308/Steps/releases) 手动下载并安装。

### 安装后页面仍显示旧内容

- 确认安装的是最新下载的 ZIP，而不是之前保存的旧包。

- 在 KernelSU / Magisk 中确认模块已启用，并重启设备一次。

- 关闭 WebUI 后重新打开；必要时在「配置 → 运行控制」点「重启全部进程」。

- 如果问题仍然存在，反馈时请附上模块版本、系统版本、Root 方案和错误截图。

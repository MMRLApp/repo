# AutoPurge Pro

**智能清理 · 文件整理 · 系统维护**

AutoPurge Pro 是一款面向 Android Root 设备的模块，将日常清理、文件扫描与分类归档、规则配置、定时任务和运行状态整合到统一的 WebUI 管理界面。

## 核心功能

- **智能清理**：集中管理模块支持的清理项目，按需启用并执行任务。

- **文件整理**：根据用户配置的扫描来源和分类规则，将文件移动归档到指定目录。

- **规则管理**：支持黑名单、白名单及 MT 文件整理规则，帮助控制处理范围。

- **自动维护**：支持定时执行，以及按分钟、小时或天设置自定义间隔。

- **运行监控**：通过 WebUI 查看设备存储信息、服务状态、任务结果、日志和统计数据。

## 管理界面

项目采用 WebUI 与设备端 Shell 后台协同工作的方式：

- WebUI 用于查看状态、编辑配置、管理规则和发起操作。

- Shell 后台负责 Root 环境检查、任务执行、调度和状态记录。

- 长耗时任务在后台运行，界面通过状态查询反馈执行结果。

## 使用要求

- Android 设备

- 可用的 Root 环境

- KernelSU 为优先适配方向；其他 Root 管理器及设备环境请以实际测试结果为准

- 建议使用支持模块 WebUI 的管理器环境

## 安全与功能边界

- 本模块不会无差别清理整个设备或所有应用缓存；实际范围由模块支持的清理项目和用户配置决定。

- APK 清理针对用户配置的共享存储下载目录。

- 模块备份清理限制在当前模块目录内。

- 文件整理属于按规则移动归档，不等同于删除文件。

- 清理预览只展示 Shell 管理的候选项目，不代表所有底层清理器的完整预览。

- 执行清理或文件整理前，请核对扫描来源、目标路径和规则；建议先备份重要数据。

## 安装与更新

- 在 KernelSU 模块管理器或兼容的 Root 模块管理器中选择本地安装。

- 选择从项目 GitHub Releases 下载的 ZIP 安装包。

- 按管理器提示完成安装，并根据需要重启或重新加载模块。

- 安装后打开 AutoPurge Pro WebUI，检查服务状态、功能开关和路径规则。

升级前建议备份配置、名单及重要数据。

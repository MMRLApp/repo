- Fixed: Bluetooth and NFC are put back reliably after a screen-off. The radio restore read its save file on stdin, so a `settings get` inside the loop could consume the next line: the Bluetooth entry after Location and the NFC entry after mobile data were skipped, and the emptied save file lost them, leaving those radios off. The save files are now read on fd 3, so every entry is handled; the same fix covers the fallback used at boot, on Revert and when the module is disabled.

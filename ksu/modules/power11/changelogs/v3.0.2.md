**Bring back the old gem from Android 11.** The classic AOSP power menu on HyperOS / MIUI, with custom items, reboot entries and blur.

### Highlights

- AOSP power menu on HyperOS / MIUI

- Pick any items in any order: Recovery, Restart, Bootloader, Power off, SystemUI, Soft reboot, Emergency, Lockdown and more

- Presets *Essential 2×2* and *All-in 2×3*, 2 or 3 columns

- Optional background blur with adjustable strength

- Black glass WebUI with live preview

### Changes in v3.0.2

- The Power11 app is now installed as a regular app, so Vector/LSPosed lists it

- Plugin components disabled by AOSP Power Menu v1/v2 are taken over correctly

### Install

- Download `Power11_v3.0.1.zip` below → KernelSU Next → Modules → Install from storage → reboot

- Vector (or LSPosed) → Modules → enable **Power11**, scope **System UI**

- Power11 WebUI → *Restart* SystemUI, then pick your items

Requires KernelSU Next and Android 12+. Vector/LSPosed is needed only for custom items and order: the AOSP menu itself works without it.

Upgrading from *AOSP Power Menu* v1/v2? Just install Power11: it replaces the old module and keeps your settings.
